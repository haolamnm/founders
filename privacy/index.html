This website

For The Founders Automation

"For The Founders Automation" is a private command-line tool. Only the owner of the For The Founders YouTube channel uses it, to publish that channel's own videos. It has no other users and is not offered to the public.

When the owner signs in with Google, the tool asks for these YouTube permissions, and uses each only for the purpose listed:

  • youtube.upload: upload the channel's videos and thumbnails.
  • youtube.force-ssl: add captions and update the channel's own video details (title, description, privacy, publish time, synthetic-content disclosure).
  • youtube.readonly: read the channel's own videos and settings to confirm an upload worked.
  • yt-analytics.readonly: read the channel's own performance reports.

The sign-in token is stored only on the owner's computer. No data obtained through Google APIs is sold, shared, transferred to anyone else, used for advertising, or used to train AI models. The tool reads no data about any viewer or any other channel.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The tool uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy. Access can be revoked at any time from Google account permissions.
